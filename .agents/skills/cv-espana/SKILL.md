# CV for Spain

Use this guide with [cv-optimizer](../cv-optimizer/SKILL.md). It adds context for the Spanish market; the user's evidence and goals remain the source for CV claims.

- Follow the language requested by the user or used in the vacancy. A role located in Spain does not automatically mean the CV must be in Spanish.
- Adapt the headline, summary, skills, experience, projects, and education to the role's actual requirements and the user's confirmed evidence. Relevant university or independent projects may be included when the user has marked them as CV evidence and they support the target role; distinguish them from employment.
- When the user asks for CareerKit's Spanish CV format, follow the two-column layout in [cv-formatos](../cv-formatos/SKILL.md): a sidebar for contact details, prioritized hard skills, and languages; a main column for the employer-adapted subtitle, short profile, selected experience, clearly separate projects, and relevant education.
- The two-column layout is a user-selected design, not a universal Spanish-market rule. For an application portal, offer a text-first single-column version when it is more suitable; no layout guarantees ATS parsing.
- Add a portrait only when the user provides and wants one. Never retrieve or invent a personal photo. If the user requests photo guidance, suggest a plain neutral background and professional clothing as an option, not a hiring requirement.
- Include phone, email, postal code and city, LinkedIn, or GitHub only when supplied and wanted; prefer city and postal code over a full home address. Do not add an identity number, birth date, or marital status by default.
- Do not use Europass or a fixed page count by default. Choose them only when the user, vacancy, or channel calls for them.
- Do not infer a right to work, nationality, language level, title, or professional experience. Ask or leave the claim out.
- If a recommendation depends on current Spanish law or a changing local convention, verify it with an authoritative current source when browsing is available. Otherwise label it as an unverified option, not a rule.

Follow the evidence, privacy, and file-handling rules in `cv-optimizer`. Never place a tailored CV or personal example in this skill or another tracked project file.
