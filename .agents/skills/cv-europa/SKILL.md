# CV for a European country

Use this guide with [cv-optimizer](../cv-optimizer/SKILL.md). Adapt recommendations to the actual destination; Europe does not have one shared CV convention.

- Identify the destination country before applying local conventions. If the user says only “Europe” and no country or vacancy makes the destination clear, ask which country to target.
- Distinguish the EU, EEA, Switzerland, and the UK. Never infer nationality, work authorization, visa eligibility, or a need for sponsorship.
- Follow the language requested by the user or used in the vacancy. Do not infer language proficiency from location or from another language in the profile.
- Treat language and layout as separate choices. Use the one-column English version only when the user selects that layout or needs an English-language CV; do not treat it as a universal European or UK convention. Read [cv-formatos](../cv-formatos/SKILL.md) for the two CareerKit layouts.
- Use confirmed, relevant evidence and the user's goals to tailor the content. Keep projects and education distinct from employment. Do not add personal or sensitive details by default.
- Do not apply one country's photo, contact, length, or design convention to another. For portal submissions, a simple text-first layout is prudent, not a guarantee of ATS parsing. Use a designed layout only when it suits the user's request and submission channel.
- Do not select Europass automatically. Use it when the user or vacancy asks for it, or when it clearly suits the selected application channel.
- For current country-specific legal or hiring-convention claims, consult an authoritative source for that country when browsing is available. If the information cannot be verified, state that limitation and present the choice as optional rather than mandatory.

Follow the evidence, privacy, and file-handling rules in `cv-optimizer`. Never place a tailored CV or personal example in this skill or another tracked project file.
